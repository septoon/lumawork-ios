# DepthStack

`DepthStack` — scroll-эффект для экранов LumaWork, где за главным верхним блоком идёт один или несколько следующих блоков.

ВАЖНО!!! Не добавляй этот файл в гит! он должен быть скрыт от публикации в гитхаб!

Команда для переноса эффекта на другой экран:

> Добавь DepthStack на экран `<название>`.

## Визуальный контракт

- Главный блок при скролле фиксируется у верхней границы контента.
- Следующие блоки продолжают обычный вертикальный скролл и проходят поверх главного.
- По мере перекрытия главный блок визуально уходит в глубину:
  - масштаб: `1.00 → 0.94`;
  - blur: `0 → 12 pt`;
  - opacity: `1.00 → 0.92`.
- Прогресс `0...1` вычисляется из фактической геометрии скролла, а не из направления жеста или отдельной анимации.
- Обратный скролл полностью и непрерывно обращает эффект.
- При включённом Reduce Motion используется обычный скролл без фиксации и depth-эффекта.
- Вторичный контент должен иметь собственный непрозрачный фон, если без него текст может смешиваться с размытым главным блоком.
- Главный блок должен находиться в удерживаемом `VStack`, а не быть прямым элементом `LazyVStack`: иначе SwiftUI может выгрузить его, когда исходная позиция далеко уйдёт за экран, несмотря на визуальную фиксацию через `offset`.
- Длинные вложенные списки и сетки можно оставлять ленивыми; удерживать нужно только верхний уровень с главным и вторичными блоками.

## SwiftUI-схема

Использовать нативные API:

- `visualEffect` и `GeometryProxy.frame(in: .scrollView(axis: .vertical))` для геометрии;
- `offset` для фиксации главного блока;
- `scaleEffect`, `blur` и `opacity` для глубины;
- `zIndex` для вывода следующих блоков поверх главного.

Нормализованный прогресс:

```swift
let pinnedOffset = max(pinY - cardMinY, 0)
let progress = min(pinnedOffset / max(cardHeight, 1), 1)
```

Не добавлять отдельный `DragGesture`, UIKit-scroll-контейнер или дублирующее состояние направления скролла.

## Несколько стадий

Для последовательного DepthStack нескольким главным блокам назначаются стадии `0`, `1`, `2` и далее:

- каждый следующий главный блок проходит поверх предыдущего;
- при достижении общего `pinY` он фиксируется и начинает собственный depth-эффект;
- обычному контенту после них назначается следующая стадия;
- при условном отсутствии первого блока стадии следующих блоков сдвигаются вниз без разрыва.

Порядок задаётся параметром `stage` у `depthStackPrimary` и `depthStackSecondary`.

### Каскад списка

Если отдельного главного блока нет, каждая карточка списка становится следующей стадией:

- заголовок и фильтры находятся вне прокручиваемой области;
- секционный заголовок текущей даты также остаётся вне прокрутки, если список сгруппирован по дням;
- первая карточка изначально стоит на общей линии фиксации и вверх не смещается;
- следующие карточки проходят поверх неё и по очереди занимают ту же линию;
- стадия карточки соответствует её текущему индексу в отфильтрованном списке.
